# Komora

Тижневий список покупок, який складається сам. Програма знає, як швидко ви споживаєте кожен товар, щонеділі питає про залишки і показує, що купити.

PWA на Preact + Vite, дані локально в IndexedDB, синхронізація з Google Sheets (етап 5).

## Розробка

```bash
npm install
npm run dev      # локальний сервер
npm test         # тести ядра і сховища
npm run build    # мініфікований білд у dist/
```

## Структура

| Шлях | Що там |
| --- | --- |
| `src/core/model.js` | прогноз, групи, кількість до купівлі, навчання (чисті функції) |
| `src/core/dates.js` | дати як рядки `YYYY-MM-DD`, день покупок |
| `src/core/constants.js` | константи моделі зі специфікації |
| `src/db.js` | IndexedDB: товари, журнал подій, черга синхронізації, резервна копія |
| `src/ui/` | екрани |
| `tests/` | тести (Vitest) |

## Публікація

Кожен пуш у `main` запускає GitHub Actions: тести → білд → GitHub Pages.
Один раз потрібно ввімкнути: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Адреса: `https://sdhnik.github.io/komora/`
