# Komora

Тижневий список покупок, який складається сам. Програма знає, як швидко ви споживаєте кожен товар, щонеділі питає про залишки і показує, що купити.

PWA на Preact + Vite, дані локально в IndexedDB, синхронізація з Google Sheets.

## Розробка

```bash
npm install
npm run dev      # локальний сервер
npm test         # тести ядра і сховища
npm run build    # мініфікований білд у dist/
```

## Структура

| Шлях | Що там |
| --- | --- |
| `src/core/model.js` | прогноз, групи, кількість до купівлі, навчання (чисті функції) |
| `src/core/dates.js` | дати як рядки `YYYY-MM-DD`, день покупок |
| `src/core/constants.js` | константи моделі зі специфікації |
| `src/core/catalog.js` | словник товарів: відповіді майстра за назвою |
| `src/core/icons.js` | словник іконок і категорій |
| `src/sync.js` | синхронізація з таблицею: відправка черги, отримання нового |
| `apps-script/Code.gs` | серверна частина в Google Apps Script |
| `src/db.js` | IndexedDB: товари, журнал подій, черга синхронізації, резервна копія |
| `src/ui/` | екрани |
| `tests/` | тести (Vitest) |

## Встановлення на телефон

Komora — це PWA: вона встановлюється з браузера і далі працює як звичайний застосунок, з іконкою на головному екрані, на весь екран і без інтернету.

**Android (Chrome)**

1. Відкрийте в Chrome **https://sdhnik.github.io/komora/**.
2. Натисніть меню **⋮** праворуч угорі.
3. Виберіть **«Додати на головний екран»** → **«Установити»**. Якщо Chrome одразу показав унизу підказку «Установити Komora», можна натиснути її.
4. Іконка з банкою з'явиться на головному екрані й у списку застосунків.

Відкривайте Komora з іконки, а не з вкладки браузера: дані зберігаються в обох, але це різні місця.

**iPhone (Safari)**

1. Відкрийте посилання в **Safari**.
2. Натисніть **«Поділитися»** (квадрат зі стрілкою вгору).
3. **«На початковий екран»** → **«Додати»**.

**Оновлення** приходять самі: після кожної публікації нова версія підтягується при наступному запуску (іноді з другого). Поточна версія — унизу в ⚙ Налаштуваннях.

**Видалення:** утримуйте іконку → «Видалити». Разом із застосунком зітруться і локальні дані, тож спершу збережіть копію або підключіть таблицю.

## Синхронізація з Google Sheets

Програма працює й без таблиці: усі дані лежать на телефоні. Таблиця потрібна, щоб дані не загубились при зміні телефона і щоб товари було зручно правити на комп'ютері. Налаштування займає ~5 хвилин і робиться один раз.

1. **Створіть таблицю.** Відкрийте [sheets.new](https://sheets.new), назвіть її, наприклад, «Komora».
2. **Відкрийте скрипт.** У меню таблиці: **Розширення → Apps Script**.
3. **Вставте код.** Видаліть усе, що є в редакторі, і вставте вміст файлу [`apps-script/Code.gs`](apps-script/Code.gs). Натисніть 💾 «Зберегти».
4. **Запустіть setup.** Угорі виберіть функцію `setup` і натисніть **Виконати**. Google попросить дозвіл: «Переглянути дозволи» → виберіть свій акаунт → «Додатково» → «Перейти до проєкту (небезпечно)» → «Дозволити». Це стандартне попередження для власних скриптів.
   Після виконання внизу відкриється **Журнал виконання** з рядком `Ключ для Komora: …`. **Скопіюйте ключ.** У таблиці з'являться аркуші `products` і `events`.
5. **Розгорніть як веб-додаток.** Угорі праворуч: **Розгорнути → Нове розгортання** → ⚙ «Вибрати тип» → **Веб-додаток**.
   - Опис: будь-який, наприклад `Komora`
   - Виконувати від імені: **Я**
   - Хто має доступ: **Усі**

   Натисніть **Розгорнути** і **скопіюйте URL веб-додатка** (закінчується на `/exec`).
6. **Підключіть у програмі.** Komora → ⚙ Налаштування → Синхронізація: вставте адресу і ключ → **Підключити таблицю**. Усі ваші товари й історія одразу підуть у таблицю.

**Новий телефон:** на екрані першого запуску натисніть «Відновити дані» → «З таблиці Google» і введіть ту саму адресу й ключ.

**Як це працює.** Кожна дія записується на телефоні й стає в чергу. Коли є інтернет, черга відправляється в таблицю, а з таблиці забирається нове. Аркуш `events` лише доповнюється. Товари в аркуші `products` можна правити вручну: правка дійде до телефона при наступному відкритті програми (новіша правка перемагає).

**Безпека.** Адреса веб-додатка й ключ разом дають доступ до ваших даних про покупки, тож не публікуйте їх. Якщо ключ потрібно змінити: Apps Script → ⚙ Налаштування проєкту → Властивості скрипту → видаліть `KEY` і знову запустіть `setup`.

**Оновлення скрипту.** Якщо `Code.gs` зміниться: вставте новий код, потім **Розгорнути → Керувати розгортаннями** → ✏ → Версія: «Нова версія» → Розгорнути. Адреса лишається тією самою.
